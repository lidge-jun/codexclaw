# Six-axis synthesis and maturity matrix

## Executive answer

CodexClaw은 OMO/Senpi보다 기능 수가 적어서 뒤처진 제품이 아니다. Codex가 실행 런타임을 소유하고 CodexClaw이 방법론·증거·완료 판단을 소유하는 thin-host 전략 때문에 비교 축이 다르다.

현재 강점:

- Persisted PABCD/FSM, Interview provenance, source-bound completion, bounded Stop continuation.
- Deterministic doctor, hook trust/retrust, exact payload freshness, candidate-SHA release design.
- Shipped Telegram/Discord bridge, approval relay, progress UX, persisted subagent settings.
- Strong recall and source-proof search doctrine.

현재 material gaps:

- Goalplan tasks/criteria를 public CLI로 생성·해결·증거 capture하는 lifecycle 부재.
- Effective V1/V2/tool capability truth가 production dispatch와 일관되게 연결되지 않음.
- Tier-3 waves/leads/claims가 structured durable state가 아님.
- Receipts가 source freshness는 증명하지만 command/result truth는 self-authored.
- Unified operator console, post-install onboarding, durable correlated telemetry 부재.
- GUI mutation result 무시, effort vocabulary drift, checkout-only GUI/map delivery.
- Static typecheck/lint/coverage 부재, plugin `src/` 기준 400줄 초과 production 파일 21개(루트 `bin` 포함 22개), win-exec 4중 복제.
- Windows real install lifecycle, persistent performance baseline, SAST/SBOM/signing 부재.
- External skill discovery에 immutable revision/hash/publisher/permission receipt 부재.

## Five strategic programs

### 1. Control-plane truth and durable execution memory

- Session-scoped effective capability snapshot for V1/V2/tool/lifecycle identity.
- Public goalplan task/criterion operations and optional research/DAG metadata.
- C3/C4 evidence-bound plan review and semantic receipts.

KPIs: zero config-only surface misroutes; zero wait-timeout child retirements; 100% task/criterion transitions through supported CLI; 100% C3/C4 final gates source-bound.

### 2. Unified operator experience

- Shipped operator console for phase, work phase, next action, criteria, receipts, doctor, trust, bridge, sessions, subagents.
- Capability-aware onboarding with <=4 decisions before a healthy default task.
- Fix false-success bridge mutations and explicit save/cancel for prompt overrides.

KPIs: median fresh-install-to-healthy-turn <5m; 0 GUI false-success mutations; 100% version vocabulary consistency; PABCD state visible within 2s.

### 3. Durable correlated operations plane

- Persist bridge events/metrics and correlate message, binding, thread, PABCD session, work phase, subagent, approval, receipt, final delivery.
- Keep live child/terminal scheduling host-native; consume authenticated host events when available.

KPIs: >=99% end-to-end traceability; 100% history across restart; 0 silent log write failures; MTTD stuck operation <2m.

### 4. Engineering static-safety and modularity

- Non-mutating typecheck/lint, staged CI, advisory then gated diff coverage.
- Split four >800 LOC modules; reduce plugin `src` files >400 LOC 21→<=8.
- Canonicalize win-exec/atomic-write/text-line helpers.

KPIs: 0 static diagnostics; 4→0 files >800 LOC; 4→1 win-exec owners; >=80% changed-file coverage after baseline.

### 5. Candidate-grade distribution, security, and ecosystem

- Real Windows install/retrust/doctor/upgrade/remove lifecycle.
- Exact-head dependency audit, secret scan, SAST, SBOM, signing, post-publish verification.
- Immutable external skill identity, permission diff, rollback receipt.
- Resolve payload `cxc map` contradiction or stop announcing it.

KPIs: 3/3 OS lifecycle green; 100% release SHA ancestry/CI/SBOM/signature; 0 mutable-HEAD skill execution; payload map smoke pass or no affordance.

## Explicit transfer decisions

ADOPT:

- OMO executable plan artifact shape, criteria coverage, adversarial QA taxonomy.
- Senpi capability-aware tool composition, permission/trust/sandbox separation as host benchmarks.

ADAPT:

- OMO claim/observation/counterevidence lineage into existing goalplan.
- OMO information model for active agents/jobs/loop state into CodexClaw operator console.
- Senpi persistent performance trends and wake-source contract as host API requirements.

DEFER:

- Named deep-research activation until durable state exists and under-fire data shows need.
- Team DAG until participant identity/liveness is trustworthy.
- Activation telemetry beyond directly observable parser/payload/receipt events.

REJECT:

- Duplicate scheduler, goal/todo DB, child engine, hidden continuation, second Stop owner.
- Global ultrawork substring parser/process-global arming.
- Permanent role explosion, always-max roster, mandatory PDF/DOCX for all research.
- OMO provider questionnaire as default onboarding, wholesale TUI implementation.
- Senpi permission kernel/terminal runtime inside CodexClaw.
