# 260802 — Interview answer capture repair

## Why this unit exists

The user reported that codexclaw's Interview asks vague, context-blind questions,
that questions arrive in batches of three, and that the options are generic
procedural filler. They asked for a comparison against jawcode's `gjc`
(`deep-interview`) and `jwc` (`jaw-interview`) implementations.

Three contradiction scan rounds (5 Mind lenses) refuted the first two hypotheses
and proved a different root cause: **the interview never learns anything, because
user answers are never recorded.**

## OPEN ASSUMPTIONS

- `A-WIRE-01` — the answer-side payload is a JSON string. Deductively supported
  (only shape consistent with 222 questions / 0 answers), not yet directly
  observed on hook stdin.
- `A-DIM-01` — question→dimension attribution uses an optional `--map` flag since
  the ledger has no dimension field. If that proves unusable in practice, a
  ledger schema addition becomes a separate cycle.
