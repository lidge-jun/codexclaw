# Explorer routing cycle lessons

Decision: keep and iterate in place. Preserve the existing hook and its new
transport regressions. No restart or additional dispatcher is justified.
Evidence: [verification](001_verification.md) and [contract](000_plan.md).

- **Partial transport coverage loses policy.** The message path applied routing
  while items returned before configuration. Keep a shared role/config owner;
  test every supported native shape with the same routing, scope, recursion and
  dispatch constraints. Attachments must remain data, in their original order.
- **Vocabulary is not an explicit role.** Negative review instructions and
  source paths selected a more expensive logical role. Preserve explicit native
  selection; retain deliberate producer headers for legacy transports. Keep
  both negative wording and legacy-header compatibility in the regression set.
- **Requested model is not served model.** Both repaired children recorded Luna,
  but correlated provider requests selected another model. The next routing
  gate must connect role, outgoing payload, child context, selected provider,
  actual model and usage. Count helper requests separately. Do not report cost
  savings from a configuration screen or a successful child alone.
- **Version strings do not preserve local changes.** Installing another checkout
  can remove additions at the same version. Keep the integration source and
  installed hashes, a backup, and a separate upstream-coverage inventory.
- **Delegation must reduce work.** The bounded items executor produced useful
  failing tests but did not finish its implementation before main took over.
  Preserve the tests and handoff; avoid repeated broad reads or overlapping
  implementation while a previous child still runs. Start with an independent
  bounded task whose returned artifact main can check directly.

The next independent investigation is proxy fallback selection. The native
tests prove CXC model delivery; their downstream rewrite does not establish
which availability condition skipped the primary. Capture that condition
before changing provider configuration or claiming the intended provider ran.
