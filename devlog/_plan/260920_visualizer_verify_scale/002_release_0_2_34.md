## Hook trust on suji

`suji` carried the doctor FAIL from the previous lane: four hooks with no trust record
and one whose recorded hash no longer matched. Approved on the host itself with
`cxc hooks retrust --key codexclaw@codexclaw`, run without `--bootstrap-ok` so the safety
pin stayed armed — 24 of 29 entries already matched their recomputed hash, which is what
that pin requires. The command backs up `config.toml`, writes atomically, re-verifies the
config through Codex and re-diagnoses every hook, rolling back on any failure. `suji` now
reports `[PASS] hook-trust: 29 hook hash(es) trusted` and `overall: PASS`.
